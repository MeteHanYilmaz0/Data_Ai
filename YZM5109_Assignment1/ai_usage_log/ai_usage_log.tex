\section*{2. Key prompts and outputs}
The student wrote the prompts in Turkish; they are translated here.
\begin{enumerate}
\item \textbf{Prompt:} ``Can you see and explain this assignment PDF? How should we do it? Could you
handle the work overnight via Colab and Hugging Face?'' The PDF link could not be opened from the AI
session, so the student pasted the assignment text.\\
\textbf{Output:} Choice of Option C with Qwen2.5-1.5B-Instruct and GSM8K, and four conditions: direct,
zero-shot chain-of-thought, PAL, and LoRA evaluated with the direct prompt. The AI also produced a
self-contained Colab notebook, a helper library, a CPU smoke test with a tiny random model, and an IEEE
report draft. The AI session had no GPU and no access to Hugging Face or Colab, so it could not run the
real experiment.
\item \textbf{Prompt:} The student uploaded the results of a 20-item pipeline check run on Colab.\\
\textbf{Output:} The AI found a bug in its own PAL scorer. Programs ending in a bare expression, such as
\texttt{total\_cost}, were scored as ``no output''. The scorer was fixed to print the final bare expression,
and regression tests were added. \emph{Disclosure:} this check used 20 test-split items. Only the
answer-parsing code changed; prompts, decoding settings and hyperparameters were not changed.
\item \textbf{Prompt:} ``Make sure the notebook is error-free.'' and ``Colab Pro lets us use L4 or A100.''\\
\textbf{Output:} The notebook was hardened with a GPU check, automatic batch size, resume-safe rescoring
and real-run defaults, and A100 was recommended.
\item \textbf{Prompt:} The student uploaded the full-run results zip.\\
\textbf{Output:} Post-hoc analysis script covering arithmetic error rate, accuracy by problem length,
complementarity and a PAL sensitivity check. The AI also completed the report and compiled it to PDF.
\item \textbf{Prompt:} The student uploaded this assignment form: ``Prepare the file I will submit according to it.''\\
\textbf{Output:} The AI checked the submission against the form. It added a second metric (answer validity rate),
prediction CSVs, an evaluation script with a terminal screenshot of the scores, configuration and prompt
files, error examples, a prompt appendix, this log and the ZIP package.
\end{enumerate}
